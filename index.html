Platform Systems

Everything the Website Controls

User Profile System

  • Core: id, username, email, avatar_id, created_at, last_login, verified
  • Extended: bio, profile_picture, social_links, status, current_world, friends_list

Avatar System

  • avatar_id, user_id, model_url, outfit_items[], animations[]
  • Integrate Ready Player Me for fast launch
  • Save + load avatar state into world

World Access Flow

  1. User logs in
  2. Click “Enter Avyra”
  3. Backend checks auth + avatar
  4. Load last location and spawn

Economy System

  • WorldCoin (earn), GoldCoin (buy)
  • Balance: user_id, worldcoin_balance, goldcoin_balance
  • Transactions table with source & timestamp

Marketplace

  • Item: name, price, category, asset_url, preview_url
  • Buy, sell, creator dashboard, ratings

Social + Chat

  • Global, room, and DM chat (Socket.IO)
  • Friends: pending/accepted/blocked
  • Notifications for events, purchases, requests

Controls & UI

How Players Move and Interact

Desktop Controls

  • Move: WASD
  • Look: Mouse
  • Interact: E
  • Run: Shift

Mobile Controls

  • Left joystick: move
  • Right swipe: camera
  • Tap: interact
  • Hold: emotes

VR Controls

  • Teleport / smooth locomotion toggle
  • Grip: grab items
  • Trigger: interact / select
  • Wrist bracelet UI for menus
