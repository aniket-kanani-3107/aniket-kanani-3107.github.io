## Sample Job Description — Senior Full Stack Engineer

We are looking for a senior full stack engineer to build user-facing web applications and scalable backend services. You will collaborate with product, design, and data teams to deliver modern SaaS experiences.

### Requirements
- 3+ years building React applications and Node.js services
- Experience with SQL databases and data modeling
- Familiarity with cloud services (AWS, GCP, or Azure)
- Strong understanding of CI/CD pipelines
- Comfortable with ATS-optimized resume writing

### Responsibilities
- Build and maintain frontend components with React and TailwindCSS
- Design REST APIs in Node.js + Express
- Optimize performance and reliability
- Ship automated PDF generation workflows
